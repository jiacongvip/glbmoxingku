# Unichant 拆图 · 出图提示词片段（配合 _模板 底板使用）

底板：`_模板/65-底板模板-用户定稿.png`（2000×2000，白身 + 黑V领 + 内外双白边 + 白内衬）

## 1. 通用开头（每条提示词都用）

```
上衣正面打板产品图（NN号 rN）。

图1 = 【底板模板】，唯一版型标准：整件外轮廓、衣长、衣宽、肩宽、肩线斜度、插肩、袖长、袖口位置、袖姿角度、下摆弧度、领口大小与形状、领圈结构——全部与图1完全一致，不许改。
图2 = NN号花色【只取花色与配色】：<衣身/袖子/下半身/领口内衬的配色>。

【要做的】
把图2的花色铺到图1的版型上：<分区描述>。
领圈保持图1的结构与白边，颜色<黑/其他>；领口内衬<颜色>。
```

## 2. 禁止项（通用尾部）

```
【禁止】
- 禁止改版型：禁止放大领口、加深V字、把袖子画低/画短/画垂、改下摆。
- 禁止改图1的袖口、插肩缝、两侧的处理方式。
- 禁止把白边画粗或去掉。
- 禁止出现<参考底板的配色>、迷彩、侧条、格子。
- 禁止任何 UNICHANT/号码/文字/logo。
透明底平面正面产品图，无人体模型，无文字，无阴影底板，背景纯透明（不要画棋盘格、不要画灰底）。
```

> ⚠️ 不要写「袖口细黑收边 / 插肩缝深色线 / 两侧无竖条」这类细节——写了模型会自己加东西，反而跑偏。这些一律以底板为准。

## 3. 领口 V 带交叉收尾（需要时才加）

```
【本轮要补的一个细节：领口V带的交叉收尾】
领口下方那条细V带（连接两片领叶下缘的那条斜带），左右两段在领口最低点【交叉叠压】：
- 右边那段压在左边那段【上面】，交叉处能看到上面那段的完整边线；
- 交叉点【下面】左边那段继续露出一小截（长度约等于带子宽度的 1.5 倍），形成一个小小的尖尾巴；
- 白线沿着每一段的边缘走，交叉处两条白线【分层、各自闭合】，不能糊成一条、不能断开。
```

实测备注（62 r4）：交叉和"小尾巴"能出来，但两条白线在交叉处容易错位叠成双层，需要再压一句：

```
- 交叉处只允许两条白线（每段各一条），不允许出现第三条白线、不允许白线错位重影。
```

## 4. 出图后的固定处理

1. rembg 抠图 → 反白底混合去白边 → alpha 内缩 1.5px
2. 按底板内容宽 1838 锁宽，高度按 1886（比值 1.024），居中贴到 2000×2000 透明画布
3. 备份旧定稿进 `_过程稿/YYYYMMDD-HHMMSS_正面_rN.png`
4. 覆盖 `01-上衣正面-2D.png`，上传七牛，写 `meta-01-rN.json`
